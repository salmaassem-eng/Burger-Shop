# 🍽️ Yummy Meals

Yummy Meals is a modern restaurant web application built with **Next.js**.  
The project provides an interactive way for users to discover meals, explore recipes, and share their own meals with the community.

## 🎯 Use Case

Yummy Meals is designed for food lovers who want to:

- Discover different meals and recipes.
- Explore detailed information about a meal.
- Find inspiration for what to cook.
- Share their own recipes with other users.
- Browse meals through a simple and engaging interface.

It can also serve as a digital platform for restaurants or food communities to showcase meals and create a more interactive experience for visitors.

## ✨ Features

### 🏠 Home Page
- Engaging landing page introducing the application.
- Interactive slideshow to highlight meals and content.
- Clear navigation to different sections of the application.

### 🍴 Meals
- Browse available meals and recipes.
- View detailed information about each meal.
- Access meal-related content through dynamic pages.
- Store and retrieve meal data using a local SQLite database.

### 👥 Community
- Dedicated community section for sharing food-related content.
- Allows users to explore meals shared within the community.
- Encourages interaction and recipe sharing between food enthusiasts.

### ⚡ User Experience
- Responsive and modern user interface.
- Loading states while content is being fetched.
- Custom "Not Found" page for invalid routes.
- Error handling for unexpected application errors.
- Smooth navigation between pages.

## 🛠️ Technologies Used

- **Next.js 15** – React framework for building the application.
- **React 19** – Building reusable and interactive UI components.
- **Tailwind CSS** – Styling and responsive UI.
- **CSS Modules** – Component-specific styling.
- **SQLite** – Storing and managing meal data.
- **better-sqlite3** – Connecting the application with SQLite.
- **JavaScript** – Application development.
